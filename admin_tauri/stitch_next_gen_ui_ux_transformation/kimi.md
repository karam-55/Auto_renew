---

## 1. الفلسفة البصرية (The Core Concept)
التصميم الجديد يعتمد على نمط **Glassmorphism** (الزجاجي المتطور) الذي يدمج بين الشفافية، الضبابية (Blur)، والتوهج (Glow) لخلق تجربة مستقبلية.

### القواعد الذهبية:
*   **الشفافية (Opacity):** استخدام خلفيات بيضاء بتركيز 70% إلى 85% مع `backdrop-blur`.
*   **العمق (Depth):** استخدام ظلال ناعمة جداً وواسعة `shadow-[0_8px_32px_0_rgba(31,38,135,0.07)]`.
*   **التوهج (Neon Glow):** العناصر النشطة والنجاح تستخدم `drop-shadow` بلون العنصر نفسه لتعطي إيحاءً بالإضاءة.

## 3. المكونات الأساسية (Global Components)

### أ. البطاقات الزجاجية (Glass Cards)
```html
<div class="bg-white/70 backdrop-blur-xl border border-white/20 rounded-2xl shadow-xl p-6 transition-all hover:translate-y-[-4px]">
  <!-- المحتوى هنا -->
</div>
```

### ب. الأزرار المتوهجة (Glow Buttons)
```html
<button class="bg-primary text-white px-6 py-3 rounded-xl shadow-[0_0_15px_rgba(0,74,198,0.4)] hover:scale-105 active:scale-95 transition-all">
  إجراء جديد
</button>
```

### ج. الجداول الحديثة
*   إزالة الحدود القاسية بين الصفوف.
*   استخدام خلفية فاتحة جداً عند التمرير (Hover).
*   الخطوط: استخدام `Be Vietnam Pro` للعناوين و `IBM Plex Sans Arabic` للنصوص.

## 4. قائمة التحقق للوكيل (Kimi's Checklist)
1.  **استبدال الخلفيات الثابتة:** تغيير كافة الخلفيات الرمادية أو البيضاء المصمتة إلى لون `#faf8ff` مع توزيع "أوربات" (Orbs) ملونة متوهجة في الخلفية بنسب شفافة جداً.
2.  **تحديث الأيقونات:** استخدام `Material Symbols Outlined` مع تفعيل خاصية `FILL=1` فقط للعناصر النشطة.
3.  **إلغاء البريد الإلكتروني:** (أمر حتمي) إزالة أي حقل أو أيقونة أو نص يشير إلى البريد الإلكتروني في كافة الواجهات.
4.  **تطبيق الانتقالات:** إضافة `transition-all duration-300` لكافة العناصر التفاعلية لضمان سلاسة "الخورافية".
